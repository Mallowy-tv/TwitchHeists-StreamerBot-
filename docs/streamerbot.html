Streamer.bot

How the extension files and import file fit together

TwitchHeists has two moving pieces in Streamer.bot: the extension files in your install folder and the imported action definitions in TwitchHeists.txt.

Extension and import

Know what lives in the folder and what gets imported separately.

The extension folder

Your Streamer.bot extension folder holds the DLLs, support files, JSON config, local database, and runtimes needed at runtime.

D:\Streamer Bot\Extensions\TwitchHeist\
  • TwitchHeists.StreamerBot.Bridge.dll is the main DLL Streamer.bot loads.
  • The other TwitchHeists DLLs and support DLLs sit beside it as dependencies.
  • data\ stores your saved points, watchtime, and game history.

The import file

TwitchHeists.txt contains the Streamer.bot actions and command wiring.

  • Import it inside Streamer.bot after your extension files are in place.
  • Re-import it when the action definitions themselves change.
  • Simple JSON setting changes do not require re-importing it.
Runtime flow

Trace what happens from a chat command to the response in chat.

  1. Streamer.bot receives a chat command or timer event.
  2. The imported action loads the bridge assembly from your install folder.
  3. The bridge reads the JSON settings and runtime data from the same extension location.
  4. TwitchHeists resolves the command, updates data, and sends back the formatted chat message.
Viewer tracking

Understand the live viewer dependency for passive rewards.

Passive points and watchtime depend on Streamer.bot keeping the present viewers list fresh during a live stream.
  • Enable Platforms > Twitch > Present Viewers > Live Update.
  • That viewer list is what the timer-driven rewards use to know who is currently active.
  • If it is off, your passive reward cycle will not behave like the public docs describe.
Update rules

Know when you need a copy-only update and when you need to re-import.

Change type What to do
DLL or code changeCopy the new release output into the extension folder.
appsettings.json changeCopy or edit the JSON file only.
heist-messages.json changeCopy or edit the JSON file only.
TwitchHeists.txt changeRe-import the file in Streamer.bot.
