Getting started

Use the shortest path to a working setup.

Fast path

  1. Download the latest release or build the solution locally.
  2. Copy the bridge release output into your Streamer.bot extension folder.
  3. Import TwitchHeists.txt in Streamer.bot.
  4. Enable Twitch present viewers live updates.
  5. Adjust JSON settings only if you want custom timing, prizes, or messages.

What TwitchHeists includes

  • Points and watchtime on a repeating timer.
  • Subscriber multipliers for the same reward cycle.
  • Free-to-enter raffles and point-risking heists.
  • Local storage beside the Streamer.bot extension.

Read top to bottom if you are setting it up for the first time.

Start with the extension folder, copied files, and import flow.

2. Learn the commands

See what chat can run and how rewards, raffles, and heists behave.

3. Edit it safely

Change JSON settings, redeploy the build output, and only re-import when action definitions change.

Keep the app files in your Streamer.bot extension folder, and keep data\ if you want to preserve saved points and watchtime.
