🎮 Streamer.bot extension docs

Run points, heists, raffles, and watchtime from one organized setup.

This site is the clean starting point for TwitchHeists: how to install it, what the commands do, how Streamer.bot fits in, where to download files, and how to edit the behavior later.

Start with install See commands Open downloads

📦 Install

Use the release files or your local build output. Copy the extension payload into your Streamer.bot extension folder, then import TwitchHeists.txt.

🧠 How it works

The extension stores points and watchtime locally, tracks active viewers, runs heists and raffles, and lets Streamer.bot trigger the chat-side actions.

🛠️ Edit it later

You can tune settings in appsettings.json, change heist wording in heist-messages.json, and re-import TwitchHeists.txt when action definitions change.

What TwitchHeists includes

💰 Points and watchtime

Active viewers earn points and lifetime watchtime on a repeating timer. Subscriber tiers earn more points from the same reward cycle.

Built-in games

🎉 Raffles and heists

Mods can run raffles, chat can join for free, and viewers can risk their own points in heists for a shot at a bigger payout.

Streamer.bot ready

⚙️ Local storage

Everything lives beside the extension in your Streamer.bot folder, including the SQLite database under data\.

🚀 Fast path

  1. Download the latest release or build the solution locally.
  2. Copy the bridge release output into your Streamer.bot extension folder.
  3. Import TwitchHeists.txt in Streamer.bot.
  4. Enable Twitch present viewers live updates.
  5. Adjust JSON settings only if you want custom timing, prizes, or messages.
