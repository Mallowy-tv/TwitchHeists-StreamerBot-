🚀 Install

Get TwitchHeists into Streamer.bot.

Use this if you want the shortest path from build output or release files to a working extension folder.

📁 Install location

Copy the extension payload into a folder like this:

D:\Streamer Bot\Extensions\TwitchHeist\
Keep your data\ folder if you want to preserve saved points, watchtime, and history.

📦 What belongs in that folder

  • The bridge release output from src\TwitchHeists.StreamerBot.Bridge\bin\Release\net48\
  • The support DLLs and runtimes\ folder that came with that output
  • appsettings.json and heist-messages.json
TwitchHeists.txt is imported in Streamer.bot. It is not part of the extension folder copy step in the local install script.

⚡ Install with the local script

If you build locally, use the included install script from the repository to copy the full deployable extension payload into your Streamer.bot folder.

Use the normal run for DLL updates, or the overwrite option if you also want to replace your JSON config files.

  • It copies the DLLs, dependency files, and runtimes\.
  • It leaves your data\ folder alone.
  • It does not copy TwitchHeists.txt.

🧩 Manual install steps

  1. Download the latest release or build the solution locally.
  2. Copy the bridge release output into your Streamer.bot extension folder.
  3. Import TwitchHeists.txt in Streamer.bot.
  4. Enable Platforms > Twitch > Present Viewers > Live Update.

✅ First checks

  • The folder contains the four TwitchHeists DLLs.
  • The folder contains the support DLLs and runtimes\.
  • appsettings.json and heist-messages.json are present.
  • Your Streamer.bot actions are imported from TwitchHeists.txt.
Need the release/build paths? Open Downloads. Need the import flow? Open Streamer.bot.
