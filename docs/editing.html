Editing

Change timings, rewards, raffle defaults, and message text

You do not need to rebuild just to tune settings or rewrite heist chat lines. Most day-to-day edits are in JSON.

Configuration files

Use the JSON files for normal tuning and wording changes.

appsettings.json

Use appsettings.json for reward timing, subscriber multipliers, heist rules, and raffle defaults.

Section Use it for
RewardsReward interval, base points, and sub multipliers.
HeistJoin window, cooldown window, min/max success chance, minimum join amount, minimum participants, and pot multiplier.
RaffleJoin window, reminder thresholds, and default winner points.

If a supported key is missing from the shipped appsettings.json, you can add it manually and the runtime will use that value instead of the code default.

heist-messages.json

Use heist-messages.json to change the chat lines used for starts, reminders, successes, failures, and join errors.

  • Edit the arrays directly.
  • Save the file.
  • The next heist action run uses the new wording.

You do not need to rebuild the DLLs just to change these chat messages.

Update flow

Rebuild only when code changes, then redeploy the output.

Updating the install after you change code

  1. Build the solution again.
  2. Copy the new release output into your extension folder, or run the included local install script.
  3. Only re-import TwitchHeists.txt if the Streamer.bot action definitions changed.
dotnet build .\TwitchHeists.sln -c Release

Common edits

  • Change raffle fallback prize: Raffle.WinnerPoints
  • Change reward rate: Rewards.BasePointsPerInterval
  • Change sub bonuses: Tier1Multiplier, Tier2Multiplier, Tier3Multiplier
  • Change heist risk: MinimumSuccessChance, MaximumSuccessChance, SuccessfulPotMultiplier
  • Change heist cooldown: Heist.CooldownWindow
  • Change the minimum !join stake: Heist.MinimumJoinAmount
The current runtime stores the database in the extension-local data\ folder. Keep that folder if you want your existing saved data to survive updates.
